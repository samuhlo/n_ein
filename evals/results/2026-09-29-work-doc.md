# TODO desde el documento de trabajo

Pi 0.87.1 cargó el paquete local en un repositorio temporal. Sin `WORK.md`, la extensión retiró el widget. Con un documento que contenía dos tareas, la petición RPC `setWidget` mostró `▸ Corregir · 1/2` bajo el editor. En una TUI real, `/todo done 2` mostró `✓ 2/2 tareas` y cambió la segunda casilla a `- [x]` en el mismo `WORK.md`.

`bun run tests/work-doc.ts` comprobó además que el widget proyecta el checklist, `done` y `add` modifican el markdown, las casillas de la sección de evidencia no se confunden con tareas y `N_EIN_WORK_DOC` puede apuntar a un documento existente.

Límite: el foco entre varios documentos se elige por `N_EIN_WORK_DOC`; todavía no hay un comando interactivo persistente para cambiarlo. El documento de trabajo y el relevo Pi↔Claude aún no se han probado juntos.
