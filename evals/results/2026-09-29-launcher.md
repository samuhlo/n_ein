# Primer launcher Go

Compilado con Go 1.27.1 y Bubble Tea v2.0.10 fijado en `go/go.mod`. El launcher lee `brand.json`, `runtime.json`, `WORK.md`, Git y sesiones de los hogares aislados. Sus cinco vistas muestran «desconocido» separado de «sin documento» o «sin sesiones». Las sesiones se filtran por proyecto y, en Claude, por petición humana; la expansión interna de una skill no aparece como última petición.

`go test ./...` y `go vet ./...` pasaron desde `go/`. En un proceso sin TTY, cada vista pintó una vez con salida monocroma y código 0. En TUI, cuatro pulsaciones de `tab` abrieron Runtime y `enter` lanzó el Pi simulado. En otro ensayo, `enter` en Sesiones pasó `--session <uuid>` al lanzador Pi. Los tests de Go comprobaron la lectura del documento, Git sucio, datos desconocidos, sesiones de dos runtimes, búsqueda y navegación.

Con `NO_COLOR` retirado, la TUI usó el amarillo de `brand.json` para el foco y los tonos neutros para el resto; con `NO_COLOR` presente, el render quedó monocromo. Bubble Tea adaptó el color a la capacidad ANSI de la terminal de prueba.

Un artefacto instalado fuera del source tree contenía ambos binarios Go y 20 archivos gestionados; `doctor` comprobó sus hashes. Su vista Configuración leyó Sol/Luna high desde `runtime.json` y el canal preview desde el marcador instalado. Runtime abrió el lanzador Pi de ese artefacto con un hogar de prueba aislado.

Tras introducir candidatos locales inmutables, un artefacto de 19 archivos instaló 21 archivos gestionados por canal. En la vista Sistema de un paquete preview, `j j j` y `enter` ejecutaron su binario `n-ein-install doctor` y verificaron el paquete; no se lanzó ningún modelo.

También se probó el **binario Go real** con `--view runtime` sobre un proyecto temporal, sin ejecutable Pi simulado. `enter` abrió Pi 0.87.1 en el directorio del proyecto con `openai-codex/gpt-6-sol` y razonamiento `high`. Una consulta de solo lectura recibió respuesta; tras salir, la vista Sesiones mostró ese turno. `enter` allí reanudó el mismo ID de sesión y Sol recordó correctamente la petición anterior. El JSONL aislado conservó ambos pares de mensajes; el único archivo del proyecto mantuvo el mismo SHA-256 (`0f08f37225329035cd2a8f3a5967abde724e89b5a12d799dbaa7c3cc4c7a2f14`). Ambos procesos salieron con código 0.

Límites: Configuración aún no edita ajustes y Sistema informa «desconocido» sobre releases remotas, que todavía no existen. El launcher no declara comprobaciones vigentes solo por encontrar texto en `WORK.md`; marca su vigencia como desconocida. No se ha probado una instalación pública ni una sesión real desde un paquete instalado en preview/estable; este ensayo usó el binario Go del checkout y su hogar de desarrollo.

El 30 de septiembre se abrió **Claude real desde la vista Runtime** del launcher Go en otro proyecto temporal. Tras confiar en esa carpeta creada para el ensayo, Claude leyó `README.md`, respondió con su título y recordó la palabra «alondra» sin escribir. La vista Sesiones mostró esa petición humana; `enter` reanudó el mismo ID de sesión de Claude, que recordó la palabra sin herramientas. El archivo temporal conservó su SHA-256 `9e6ef33a52f6f8ac1007f4c55405d058ac38572ff6ad5c74cfdd70ba6ff32219`; ambos procesos salieron con código 0. No se probó un canal preview autenticado ni una sesión con cambios de código.
