# Primer launcher Go

Compilado con Go 1.27.1 y Bubble Tea v2.0.10 fijado en `go/go.mod`. El launcher lee `brand.json`, `runtime.json`, `WORK.md`, Git y sesiones de los hogares aislados. Sus cinco vistas muestran «desconocido» separado de «sin documento» o «sin sesiones». Las sesiones se filtran por proyecto y, en Claude, por petición humana; la expansión interna de una skill no aparece como última petición.

`go test ./...` y `go vet ./...` pasaron desde `go/`. En un proceso sin TTY, cada vista pintó una vez con salida monocroma y código 0. En TUI, cuatro pulsaciones de `tab` abrieron Runtime y `enter` lanzó el Pi simulado. En otro ensayo, `enter` en Sesiones pasó `--session <uuid>` al lanzador Pi. Los tests de Go comprobaron la lectura del documento, Git sucio, datos desconocidos, sesiones de dos runtimes, búsqueda y navegación.

Con `NO_COLOR` retirado, la TUI usó el amarillo de `brand.json` para el foco y los tonos neutros para el resto; con `NO_COLOR` presente, el render quedó monocromo. Bubble Tea adaptó el color a la capacidad ANSI de la terminal de prueba.

Un artefacto instalado fuera del source tree contenía ambos binarios Go y 20 archivos gestionados; `doctor` comprobó sus hashes. Su vista Configuración leyó Sol/Luna high desde `runtime.json` y el canal preview desde el marcador instalado. Runtime abrió el lanzador Pi de ese artefacto con un hogar de prueba aislado.

Límites: Configuración aún no edita ajustes y Sistema informa «desconocido» sobre releases remotas, que todavía no existen. El launcher no declara comprobaciones vigentes solo por encontrar texto en `WORK.md`; marca su vigencia como desconocida. No se ha probado una instalación pública ni una sesión de producción iniciada desde el launcher Go.
