# Release de hotfix desde rama

`hotfix/model-selector` se creó en un worktree aislado desde el tag `v0.1.0-preview.1` (`d641eeab9d601f494ffc159a2df563b81c3e31ab`), sin mover el checkout `main`. Se llevó el cambio del selector por cherry-pick y el soporte mínimo para publicar. El guard comprobó que la bifurcación y el merge-base con `main` eran el tag base y que había un cambio de runtime; rechazó `main` como origen de este tag. La rama [pasó CI](https://github.com/samuhlo/n_ein/actions/runs/36855499949).

El primer intento de tag falló antes de los tests porque el guard invocaba `rg` antes de que CI lo instalase. No existía aún una release ni assets. Se sustituyó ese tag inédito tras quitar la dependencia de `rg`; el guard también pasó en un checkout detached local. El tag final `v0.1.0-preview.1.hotfix.1` apunta a `33eee2c679c2f323ce048c776ff78e03ec67c899`. Su [CI](https://github.com/samuhlo/n_ein/actions/runs/36855676867) pasó procedencia, checks, build nativo Linux amd64 y subida del artefacto.

El candidato macOS arm64 se construyó nativamente desde el mismo commit. Ambos `.tar.gz` pasaron sus SHA-256: `a63186817db18cbd27388ea00837dd2859d0735833be0def9fbaff747a834a95` (macOS) y `fbd9fbdf6e430f688a82d16e4755357671be3d2a7e509ebf64368aaa1407af17` (Linux). Sus manifests tienen versión `0.1.0-preview.1.hotfix.1`, ese commit y 21 archivos; los únicos hashes de archivo diferentes son `bin/n-ein` y `bin/n-ein-install`. Se publicó la [prerelease](https://github.com/samuhlo/n_ein/releases/tag/v0.1.0-preview.1.hotfix.1) con esos tarballs y sus `.sha256`.

Después se descargó de GitHub el tarball macOS, se verificó el hash y se instaló en `/tmp`: `doctor --runtime` verificó 23 archivos instalados, Pi 0.87.1 y Bun; Configuración mostró Sol/Luna high y `/models`. No se probó una llamada al modelo desde esa instalación temporal. Un diff entre `main` y `hotfix/model-selector` sobre los archivos de runtime quedó vacío, por lo que no se duplicaron commits mediante un merge. El canal personal preview sigue en `0.1.0-preview.1+hotfix.19650ed7eaa7`, con su backup válido de la release base; la release de rama no lo reemplazó.
