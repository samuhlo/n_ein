# n_ein 0.1.0-preview.1

Primera preview instalable de n_ein. Conserva el launcher de cinco vistas, instalador con backup/restore, estilo y voz de Ein, TODO en `WORK.md`, `intent`, trabajo directo con GPT-6 Sol high, trabajador GPT-6 Luna high y relevo Pi↔Claude. Los modelos usan las suscripciones iniciadas en los hogares aislados de n_ein.

Los archivos adjuntos contienen **el mismo paquete funcional** compilado de forma nativa para macOS arm64 y Linux amd64. Cada `.tar.gz` tiene un `.sha256` y contiene `package-manifest.json` con commit, digest y hashes de los archivos. El instalador comprueba ese manifest antes de instalar. El repositorio histórico y las credenciales no entran en el paquete.

Para instalar la preview en macOS arm64, sigue los [comandos del README](../../README.md#instalación-local-de-prueba). Linux amd64 usa el archivo con ese sufijo; el smoke de Linux corre en GitHub Actions. El recorrido interactivo con modelos y el relevo real se comprobaron en macOS, no en Linux. Hace falta Bun y Pi 0.87.1; Claude es opcional. Preview guarda credenciales y sesiones separadas de desarrollo y de Ein.

Esta preview no activa actualizaciones remotas desde la TUI ni edita modelos desde Configuración. Los cambios de paquete se aplican con `n-ein-install update --source`, y `restore` devuelve la versión anterior. Qwen local queda aplazado por decisión de Samu hasta tener el equipo objetivo.
