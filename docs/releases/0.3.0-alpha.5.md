# n_ein 0.3.0-alpha.5

Claude deja de cargar el `~/.claude/CLAUDE.md` global: Pi y Claude reciben las mismas reglas del usuario desde `~/.n_ein/preferences.md`, en cualquier carpeta. Llega también un medidor del contexto de las sesiones.

## Reglas del usuario en un solo sitio

- **Antes:**
  - Las sesiones de Claude abiertas por n_ein cargaban `~/.claude/CLAUDE.md` solo si el proyecto vivía bajo la carpeta personal, porque Claude Code lo encuentra al subir por las carpetas.
  - En un proyecto fuera de ella, como `/tmp`, no lo cargaban. Pi no lo recibía nunca.
- **Ahora:**
  - El lanzador pasa a Claude el ajuste `claudeMdExcludes`, que deja fuera `~/.claude/CLAUDE.md` y `~/.claude/rules/**`.
  - El `CLAUDE.md` de cada proyecto se sigue cargando.
  - El Claude Code de siempre, fuera de n_ein, no cambia.
- **Qué hacer:** si quieres que n_ein siga alguna regla de tu `~/.claude/CLAUDE.md`, como el gestor de paquetes, el estilo de TypeScript o la atribución en commits, cópiala en `~/.n_ein/preferences.md`. Ese archivo llega a Pi y a Claude, por debajo del encargo, el idioma elegido y las convenciones del proyecto.

Comprobado en sesiones reales con Claude 2.1.302, la versión que instala n_ein, y con la 2.1.308.

## Medidor del contexto

`bun evals/bench/context-load.ts <sesiones>` lee sesiones grabadas de Pi y Claude, sin llamar a ningún modelo. Muestra:
- el contexto con el que arranca cada sesión;
- qué tipo de herramienta lo va llenando después, en caracteres y en lo que se vuelve a leer en cada turno.

La primera medición está en `evals/results/2026-10-22-contexto-inicial.md`.

- **Pi:** arranca con unos 5k tokens. La salida de tests y builds es solo el 2–3 % de lo que devuelven las herramientas.
- **Claude:** el arranque lo llenan sobre todo los esquemas de sus herramientas propias y los conectores de la cuenta de claude.ai. Un conector se puede apagar solo para un proyecto desde `/mcp`.

El flujo y CodeGraph no cambian.

## Actualización

En el canal preview, abre `nein` y elige **Actualizar** (`u`). El aviso usa una caché de seis horas. Para actualizar de inmediato:

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash -s -- --channel preview
```

La actualización conserva autenticación, sesiones, modelos y preferencias, y crea un backup. Cierra las sesiones antes de actualizar.

## Plataformas

macOS arm64 y Linux amd64 (Ubuntu, Arch), comprobados en CI con instalación limpia y actualización con restore. La sesión gráfica en Omarchy se comprueba a mano.
