# n_ein 0.8.0-alpha.2

Versión de mantenimiento del canal **preview**: actualiza los programas base sin cambiar el código de n_ein. La comprobó la matriz completa en macOS y Linux (suite sin modelos, plugin de Claude, instalación limpia, actualización y vuelta atrás) antes de publicarse.

## Programas base

- Pi: 1.5.2 → 1.6.0
- CodeGraph: 1.6.3 → 1.6.4

## Cambios incompatibles de Pi

Pi los declara para extensiones e integraciones; la suite de n_ein pasó con ellos.

- 1.6.0: Extension components: `render()` now returns `readonly string[]`, and `Container` returns the same cached array while its children are unchanged.

## Actualizar

Pulsa `u` en la portada del launcher. Si algo no va bien, Sistema → «volver a la versión anterior» restaura la instalación previa; las sesiones creadas con un Pi más nuevo pueden no abrirse con el anterior.
