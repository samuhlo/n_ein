# n_ein 0.7.0-alpha.1

Esta alpha del canal **preview** mantiene al día Pi, Claude Code, el puente de Claude y CodeGraph. Un vigía en GitHub prueba cada versión nueva con la matriz completa y, si nada se rompe, la publica como preview que el launcher ofrece con `u`. Trae también la primera subida.

## Programas base al día

- Pi 1.0.2 → 1.5.2, puente de Claude 0.9.3 → 0.12.0, Claude Code 2.1.302 → 2.1.311 y CodeGraph 1.6.1 → 1.6.2. Los modelos nuevos de Claude llegan al puente con Pi; los de OpenAI ya llegaban por el catálogo de Pi.
- Cada día, el vigía busca versiones nuevas: espera 3 días tras cada publicación, sube Pi y el puente juntos según lo que admite el puente y sigue el canal estable de Claude Code. Las aplica sobre la última preview publicada y pasa la batería completa en macOS y Linux: suite sin modelos, plugin de Claude, instalación limpia, actualización y vuelta atrás.
- Si pasa, publica una preview de mantenimiento y abre la PR del mismo commit a main. Si falla, prueba cada grupo por separado, bloquea lo que rompe en un issue y publica el resto.
- Un puente con llamadas de red nuevas no entra hasta que lo revisas: el vigía abre un issue y lo apruebas cerrándolo como completado.
- Una release normal ya no puede bajar los runtimes que el vigía publicó.

## En el launcher

- El aviso dice qué trae la versión nueva: debajo de `▲ nueva versión … · u actualizar` aparece, por ejemplo, `trae Pi 1.6.0 · Claude Code 2.1.330`. Sistema marca cada runtime que cambia y enseña lo que el vigía no publicó y por qué.
- `doctor --runtime` arranca Pi con las extensiones de n_ein y un proveedor local, sin red, sin login y sin tus ajustes. Si una actualización no lo pasa, vuelve sola a la versión anterior.
- Sistema → «versión anterior» restaura la instalación previa tras confirmar, y avisa de que las sesiones creadas con un Pi más nuevo pueden no abrirse con el anterior.
- Tras actualizar se borran los runtimes sin uso (se conservan los de la versión actual y la anterior) y quedan los tres backups más nuevos.

## Actualización y datos

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash -s -- --channel preview
```

Cierra las sesiones de n_ein antes de actualizar. Autenticación, preferencias y sesiones permanecen en su hogar nativo.

- La primera actualización a esta versión instala Pi 1.5.2, Claude Code 2.1.311, el puente 0.12.0 y CodeGraph 1.6.2 junto a los anteriores, y después limpia: conserva los runtimes de 0.6.0-alpha.1 para poder volver atrás y recorta los backups de la instalación a tres.
- Si actualizas desde una versión anterior a 0.4, siguen aplicándose las precauciones de las [notas de 0.4.0-alpha.1](0.4.0-alpha.1.md).
