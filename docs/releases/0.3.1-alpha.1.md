# n_ein 0.3.1-alpha.1

Retoques en la portada del launcher: el aviso de versión nueva deja de mover la pantalla, se ve qué versión está instalada y Pi ya no lleva el modelo al lado.

## Aviso de versión nueva

- **Antes:** ocupaba tres filas y botaba entre ellas sin parar, así que la portada daba saltos.
- **Ahora:**
  - Tiene una sola fila fija. Al aparecer parpadea dos veces y se queda.
  - Mientras está apagado deja el hueco, así que el menú no se mueve.
  - Si llega durante la apertura, el parpadeo empieza cuando la portada termina de dibujarse.
  - Después del parpadeo, la portada deja de redibujarse.

## Versión instalada

Al pie de la portada, debajo de los atajos: `n_ein 0.3.1-alpha.1 · preview`.

## Pi sin modelo al lado

Pi ya no lleva el modelo al lado: se elige y se ve dentro de Pi, y la vista Configuración lo sigue mostrando. Como en Claude Code, la fila solo lleva nota cuando no se puede abrir, para decir por qué.

## Actualización

En el canal preview, abre `nein` y elige **Actualizar** (`u`). El aviso usa una caché de seis horas. Para actualizar de inmediato:

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash -s -- --channel preview
```

La actualización conserva autenticación, sesiones, modelos y preferencias, y crea un backup. Cierra las sesiones antes de actualizar.

## Plataformas

macOS arm64 y Linux amd64 (Ubuntu, Arch), comprobados en CI con instalación limpia y actualización con restore. La sesión gráfica en Omarchy se comprueba a mano.
