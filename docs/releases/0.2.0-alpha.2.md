# n_ein 0.2.0-alpha.2

Segunda alpha: Claude Code pasa a instalarse con n_ein, igual que Pi, y la marca pequeña aparece bajo el prompt de Claude.

## Cambios

- Claude Code 2.1.302 se instala desde npm con lockfile congelado en `~/.n_ein/runtimes/claude/2.1.302`, mediante `nein-setup` o `n-ein-install runtime`. Ya no hace falta tener `claude` instalado en el sistema.
- n_ein usa siempre esa copia propia, con el autoactualizador desactivado: Claude se actualiza al subir la versión fijada en n_ein. El `claude` del sistema no se usa ni se modifica. La configuración y el login siguen en `~/.n_ein/<canal>/claude`.
- El Panel y el lanzador de Claude eligen el binario con la misma regla (`n-ein-install claude-path`).
- Dentro de Claude, la marca pequeña del instalador ocupa la zona derecha bajo el prompt; los modos de Claude se muestran encima.
- La instalación descarga unos 260 MB más por Claude.

## Instalación y actualización

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash
```

Sobre 0.2.0-alpha.1 o preview.3 se actualiza con backup; autenticación, sesiones, modelos y preferencias se conservan. Cierra las sesiones de n_ein antes de actualizar. `… | bash -s -- --dry-run` muestra el plan sin escribir.

## Plataformas

macOS arm64 y Linux amd64 (Ubuntu, Arch), comprobados en CI con instalación limpia. La sesión gráfica en Omarchy se comprueba a mano.
