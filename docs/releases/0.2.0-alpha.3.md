# n_ein 0.2.0-alpha.3

Tercera alpha: el launcher avisa de versiones nuevas y actualiza desde la portada, y Claude Code abre con la marca pequeña animada.

## Cambios

- Al abrir, el launcher consulta en segundo plano la última release de su canal, como mucho una vez cada seis horas. Si hay una más nueva, un aviso bota en la portada y aparece `u Actualizar`: descarga y verifica la release como el curl, instala con backup y vuelve a abrir la portada actualizada. Sin red no hay aviso y la portada no espera.
- Al aparecer el aviso, el foco se queda donde estaba: un `enter` por costumbre no actualiza.
- La vista Sistema muestra la versión disponible en «actualizaciones».
- En Claude Code, la marca pequeña del instalador sustituye a la grande encima del prompt: sus palas giran al abrir la sesión y se retira con el primer mensaje. Se quita la marca del pie.

## Instalación y actualización

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash
```

Las versiones anteriores a esta no traen el aviso: actualiza una vez con el curl. Desde 0.2.0-alpha.3, el launcher avisa solo. Cierra las sesiones de n_ein antes de actualizar.

## Plataformas

macOS arm64 y Linux amd64 (Ubuntu, Arch), comprobados en CI con instalación limpia.
