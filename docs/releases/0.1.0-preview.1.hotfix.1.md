# n_ein 0.1.0-preview.1.hotfix.1

Release de mantenimiento desde `hotfix/model-selector`, creada a partir de `v0.1.0-preview.1`. Añade `/models` para elegir modelo y esfuerzo del principal y del trabajador actual desde el catálogo de Pi. La elección se guarda por canal fuera del paquete, por lo que sobrevive a `update` y `restore`. Los valores predeterminados siguen siendo GPT-6 Sol high y GPT-6 Luna high.

La rama contiene la corrección del selector y el soporte de publicación de hotfix, sin arrastrar los demás cambios posteriores de `main`. Los paquetes macOS arm64 y Linux amd64 se generan de forma nativa desde el tag y tienen manifest con commit, hashes de archivos y SHA-256 del tarball. Es una prerelease de la misma línea preview; no promueve el canal estable.

Para actualizar una instalación preview existente, verifica el `.sha256`, extrae el tarball de tu plataforma y ejecuta `bin/n-ein-install update --source <directorio-extraído> --channel preview`. El instalador guarda un backup y `n-ein-install restore --channel preview` vuelve a la versión anterior. Una instalación local con `+hotfix.<commit>` puede conservarse sin actualizar: esta release de rama es la segunda vía, no un reemplazo forzoso.
