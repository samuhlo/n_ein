# n_ein 0.3.0-alpha.2

Hotfix de 0.3.0-alpha.1: permite abrir varias conversaciones de Pi o Claude en el mismo proyecto desde terminales distintas.

- Una sesión abierta o suspendida con `Ctrl+Z` ya no impide abrir otra ni retomar una conversación cerrada desde `nein`.
- El launcher deja de aplicar el bloqueo general por árbol. También permite abrir una sesión aunque una versión anterior conserve ese bloqueo; no termina ni modifica el proceso anterior.
- Cada relevo Pi↔Claude sigue esperando a que termine su propia sesión de origen y sus herramientas. Se conserva la propiedad de los trabajadores del equipo experimental.

Las sesiones independientes comparten los archivos del proyecto. Para trabajos que se solapen, coordina las ediciones o usa worktrees.

## Actualización

En el canal preview, abre `nein` y elige **Actualizar** (`u`). El aviso usa una caché de seis horas, por lo que puede tardar en aparecer si ese equipo comprobó las versiones recientemente. Para actualizar de inmediato:

```sh
curl -fsSL https://samuhlo.github.io/n_ein/install.sh | bash -s -- --channel preview
```

La actualización conserva autenticación, sesiones, modelos y preferencias, y crea un backup. Cierra las sesiones antes de actualizar; `Ctrl+Z` las deja suspendidas.

## Comprobación

El arreglo reproduce aperturas Pi→Pi, Pi→Claude, Claude→Pi y Claude→Claude con el primer proceso activo y suspendido, además de un bloqueo conservado por una versión anterior. La matriz de publicación comprueba macOS arm64 y Linux amd64, la instalación limpia en Ubuntu y Arch, y la actualización con restore desde paquetes verificados. El recorrido gráfico de Omarchy se comprueba en uso real.
